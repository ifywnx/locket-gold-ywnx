# Bộ cài gốc

Bản xuất từ bộ cài đang phục vụ trên web ngày 17/10/2026, không phải bản upstream.

Cách cài khuyến nghị: Config → DNS (DNS tuỳ chọn). Nếu đã có cấu hình Shadowrocket riêng thì chỉ cài Module thay thế. Không bật đồng thời Config Locket và Module Locket vì chúng chứa các quy tắc trùng. DNS hiện tại: ifywnx · DNS riêng (NextDNS). Bản DNS trước đổi nằm trong `DNS dự phòng/`.

Các file giữ nguyên nội dung để đối chiếu. URL nội bộ là mẫu được máy chủ thay thành đường dẫn có xác thực khi tải. Các đường dẫn raw cũ ở gốc repo đã dọn; khách cài qua website.
